# 什么是OpenClaw

是一个可以7 * 24 小时运行在个人设备上的自主AI Agent
{% asset_img openClaw.jpg openClaw其人 %}

Gateway:身份鉴权、管理会话状态、决定转发给哪个组件去处理
Agent:可以调用大模型的 AI任务的执行框架
Channels:对外通信方式转成AI能看懂的格式
Nodes:Nodes传感器终端，为智能体提供摄像头、地理位置、屏幕画面渲染或系统控制等本地级的高权限能力

# OpenClaw的核心亮点

* 多平台一键打通
* 权限很大
* 技能生态庞大，掌握新能力极容易
* 7 * 12 小时自动干活
* 自我修正自我净化，可以自己总结错误经验
* 真正的永久记忆（本地储存）

# OpenClaw的记忆化机制

为了解决长文本遗忘，OpenClaw放弃了重型的外部向量数据库，使用了一套**纯md文件**加上**轻量级SQLite**的混合记忆流

1. 短期记忆
存放在sessions
2. 长期记忆
在聊天记录过长、快要触发压缩时，OpenClaw会强制大模型做个阅读理解，把聊天中的重要事实或新知识提炼出来，写入MEMORY.md长期记忆
格式如下：
```agsl
# 核心事实与偏好 MEMORY.md

## 用户画像与技术栈
职业身份技术博主、资深开发工程师。
核心技术精通 Java 和 SpringBoot 开发，对计算机网络底层原理和 Linux 操作系统有深入研究。
沟通偏好不喜欢长篇大论的空话，偏好图文并茂、大白话的技术解释风格。

## 关键历史项目与近期关注
2026-02-15 记录用户正在规划图解网络相关的系列内容，后续回答网络问题时需注重图解表达。
2026-03-07 记录用户近期上线了小林简历网站业务，需要偶尔留意协助排查该网站的运行状态。
2026-03-20 记录用户要求以后生成后端代码示例时，优先采用 Java 17 的新特性，并且代码要干净，不需要写多余的废话注释。
```
当MEMORY.md越来越大，模型的分析速度会越来越慢，于是引入了**SQLite**

MEMORY.md写入的新内容会被分成一个个小块，转换成多维向量存进SQLite

下次用户提起相关话题，问题本身也会被转换成向量，然后直接在SQLite中进行相似度对比，同时结合**BM25**进行关键词匹配

# Coze、n8n 和 OpenClaw的区别在哪里

- Coze:云端AI应用搭建平台，适合轻量级的对外交互，摸不到本地核心代码业务，数据和权限全在云端
- n8n:开源工具流自动化平台，核心是基于触发器和条件判断，确定性极强
- openclaw:本地AI智能体
