# “#”是一级标题

# “##”是二级标题

# “###”是三级标题

## 列表

### 无序列表

“-”或“*”

“- 安卓开发
“- 前端开发
* HTML（缩进两个空格就能嵌套）
* CSS” 的效果：
- 安卓开发
- 前端开发
    * HTML（缩进两个空格就能嵌套）
    * CSS

### 有序列表

"1."

1. 第一步：新建项目
2. 第二步：导入依赖
3. 第三步：运行

## 代码块

“```”

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello World!");
    }
}
```

## 引用

">"

> 这是一段引用文字，一般会有个竖线在旁边。


## 链接和图片

"{% asset_img 1.jpg 这是一张图 %}"

{% asset_img 1.jpg 这是一张图 %}

“[4399](https://www.4399.com)”  （中括号写名字，小括号写网址）

[4399](https://www.4399.com)  

## 加粗

“**”

## 斜体

“*”

## 删除

“~~”
### *示例*

1. **第一步**：新建项目
2. **第二步**：导入依赖
3. **第三步**：运行
~~4. **第四步**：下班~~
